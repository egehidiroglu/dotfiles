# Wallpapers — Nokia 3310 Japan division

Curated sources for the aesthetic. None of these are auto-downloaded — the vibe is personal, and these places update.

## The big four collections

**unixporn / r/unixporn** — go look at the desktops people post and you'll find the wallpapers in the comments. Filter by "macOS" or "i3" for tiling-WM-friendly setups. Many are linked to the same Pinterest boards and Wallhaven dumps.
→ https://reddit.com/r/unixporn

**Wallhaven** — best general source. Filter by resolution ≥ 5120×2880 (5K, retina), aspect 16:10 or 16:9. Try these tags:
- `cyberpunk`
- `vaporwave`
- `synthwave`
- `tokyo + neon`
- `night + city + rain`
→ https://wallhaven.cc

**Pinterest "Y2K aesthetic" boards** — for the actual Nokia-3310-Japan-feels look. Search:
- "Y2K interface aesthetic"
- "Japanese keitai aesthetic"
- "frutiger aero"
- "98 desktop wallpaper"
- "dreamcore tech"

**Behance / Dribbble** — for original cyberpunk/Tokyo work by named artists. Search "Tokyo neon", "cyberpunk dashboard", "anime city skyline".

## Specific artists worth checking

- **Beeple** (Mike Winkelmann) — has decades of free 4K renders, many in the cyberpunk/dystopian-tech vein. https://www.beeple-crap.com/resources
- **Simon Stålenhag** — lo-fi cyberpunk Swedish countryside, but the same retro-tech-melancholy energy. http://simonstalenhag.se
- **Ash Thorp** — concept artist, Blade Runner 2049 / cyberpunk vibe. Often releases wallpaper-grade renders.

## CLI option

`brew install --cask wallpapper` — no, wait, that's a wallpaper generator. There's a tool called `wallpaper` (npm) that lets you set the desktop wallpaper from a script:

```bash
npm install -g wallpaper-cli
wallpaper ~/Pictures/Wallpapers/some-cyberpunk-tokyo.jpg
```

You can wire that into a daily cron with `~/Pictures/Wallpapers/*.jpg` randomized.

## Mac-specific tips

- **Multiple wallpapers, one per Space:** System Settings → Wallpaper → Add a folder with 10+ images → "Show on all Spaces" off → set per-Space.
- **Dynamic wallpapers** that shift with macOS dark/light mode: 24-hour timelapses of cities work great. Search "dynamic wallpaper macOS" + "Tokyo" / "Hong Kong" / "Kowloon".
- **Apple's hidden ones:** macOS already ships with several aerial/timelapse wallpapers in System Settings → Wallpaper. The "Hong Kong" and "Sonoma" ones are tasteful default fallbacks while you're hunting.

## What I'd pick if forced

Open one Wallhaven tab with the search `tokyo neon night rain @ 5K`, sort by toplist month, scroll for 90 seconds, save five. Done. Don't optimise — wallpapers are disposable, swap them weekly.
